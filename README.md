# AI Miniature Video Biz Concepts

A working knowledge base for developing, validating, and potentially launching AI-generated miniature-video businesses.

## Purpose

This repository is designed so a new ChatGPT conversation, collaborator, or future session can quickly recover the project's context without rereading old chats.

The core idea is broader than "make miniature AI videos." The opportunity is to use miniature/scale-model visual treatments as a **pattern interrupt** around real products, properties, businesses, and other high-value subjects, then attach a business model to that attention.

## Current Leading Thesis

The strongest opportunity currently appears to be **AI-native listing media for real estate**, using realistic miniature/unboxing treatments as the signature creative format.

Rather than depending on YouTube ad revenue, the business can sell directly to realtors, teams, builders, developers, brokers, resorts, or other property marketers. Public social content then doubles as portfolio, customer acquisition, and potentially affiliate/sponsorship inventory.

## Important Principle

Do not build a company whose only moat is "we know how to make things miniature." Miniature generation is rapidly becoming a feature/button.

The defensible system is closer to:

**asset intake -> property/product understanding -> creative concept -> generation -> quality control -> branding/CTA -> distribution -> analytics -> learning**

## Knowledge-Base Rules

- `PROJECT_STATE.md` should always reflect the latest truth.
- `HANDOFF.md` should be rewritten at the end of a major chat/work session.
- Stable conclusions go in `docs/`.
- New ideas should go in `docs/08-ideas-backlog.md` until validated.
- Research claims should include a date and source when possible.
- Anything uncertain should be labeled **Hypothesis**, **Unverified**, or **Needs revalidation**.
