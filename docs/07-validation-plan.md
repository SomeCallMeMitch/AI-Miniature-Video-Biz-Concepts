# Validation Plan

## Goal

Answer the highest-risk questions with the least money and effort before building software, a brand, or a large content library.

## Stage 1 — Technical proof

Budget target: **$100-$200 total**

Create:

- 3 miniature product prototypes
- 3 miniature real-estate prototypes

Choose varied subjects so the test is meaningful.

### Product tests

Use recognizable categories with obvious physical interaction, such as:

- drone
- camera
- power tool / power station

### Property tests

Use varied property styles, such as:

- suburban single-family home
- luxury property
- condo/cabin/modern home

### Score every prototype

1-10 scale for:

- realism
- subject fidelity
- consistency between shots
- hand interaction quality
- miniature illusion
- visual hook
- production speed
- repeatability

Also record:

- generations/retries
- model cost
- edit time
- total cost

### Technical go/no-go

Proceed only if we can repeatedly produce something that feels genuinely surprising rather than merely "AI-looking."

The desired reaction is roughly:

> How did they make that?

not:

> That's obviously an AI effect.

## Stage 2 — Organic attention test

Post selected prototypes as Shorts/Reels/TikToks.

Do not judge only by raw views. Compare against reasonable baselines and watch:

- first-second/first-3-second retention where available
- average watch time
- completion rate
- rewatches
- shares
- saves
- comments
- profile/link actions

Test multiple formats, not only multiple subjects.

Examples:

- tiny unboxing
- house in hand
- real -> mini transition
- roof-off reveal
- guess the price

### Attention go/no-go

Proceed to sales test if the miniature creative shows materially stronger stop-scroll/retention behavior or generates obvious qualitative interest.

## Stage 3 — Realtor willingness-to-pay test

Create personalized watermarked previews for **20-50 agents**.

Prefer agents with:

- active listings
- decent listing media
- visible social activity
- higher listing values or listing volume

Send a very short personalized note plus preview.

Track:

- delivered
- opened/viewed if measurable
- replied
- positive response
- asked price
- purchased
- objections

### Pricing test

Do not assume one price. Test a small range, for example:

- $79 entry
- $149 core
- $249 premium

The goal is to learn elasticity and what buyers actually value.

## Stage 4 — Package test

If individual videos sell, test a broader listing-content pack.

Possible package:

1. miniature hero Reel
2. miniature unboxing
3. real-mini-real transition
4. guess-the-price Reel
5. still covers
6. captions/CTA variants
7. conventional derivative Reel

Test whether packaging raises willingness to pay enough to offset production cost.

## Stage 5 — Recurring revenue test

Target:

- high-volume agent
- realtor team
- brokerage
- builder/developer

Offer a monthly package tied to new listings or a fixed asset quota.

## Stage 6 — Automation

Only automate steps that are repeated, understood, and economically justified.

Automation candidates:

- lead discovery
- asset intake
- prompt generation
- format selection
- batch generation
- watermarking
- preview assembly
- delivery
- CRM/status tracking
- analytics

Do not automate strategic uncertainty.

## Success criteria for the first phase

A reasonable early green light would look like:

- at least one production workflow that is repeatable
- client-ready quality without excessive retries
- plausible cost per finished asset
- organic evidence that the format earns attention
- at least some agents willing to pay

## Kill criteria

Pause or pivot if:

- fidelity to real listings is unreliable
- generation costs require pricing buyers reject
- human correction time is too high
- organic viewers do not show better engagement
- personalized agent outreach gets interest but no willingness to pay

The purpose of the experiment is to learn cheaply, not to prove the idea must work.
