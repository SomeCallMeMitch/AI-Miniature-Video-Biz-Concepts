## Adjacent service markets

### Builders / developers

"Watch us build this community in miniature."

Potentially higher marketing budgets and repeatable projects.

Miniature resort-in-your-hand reveal, then transition to the real destination.

### Vacation rentals / Airbnb-style properties

Miniature property tour used as a booking/ad creative.

### RV dealers

Miniature RV exterior, hand opens side/roof, interior revealed.

### Yacht brokers

High visual novelty + very high transaction values.

## Content system idea

Rather than one video per listing, treat each listing as a content object that can generate multiple recurring shows:

- Tiny House Tour
- Would You Pay $X For This?
- $500K Here vs $500K There
- Guess The Price
- Fix This House
- Most Expensive House in [City]
- Tiny Dream Homes
- What's Behind This Door?

This reduces the risk of repetitive template content while giving the brand recognizable series.

## Longer-term software concept

If the service validates, potentially build a system where a user submits listing/product assets and selects an objective/format.

Potential output:

- miniature images
- short videos
- captions
- branded CTA
- thumbnails/covers
- multiple aspect ratios
- watermarked preview
- final delivery

Do not build this before the manual/semi-manual service proves demand.
